Documentação Técnica Oficial do ForjaOS

A distribuição workstation local-first imutável projetada para engenheiros de sistemas, desenvolvedores de jogos e IA generativa embarcada. Totalmente auditável, baseada em nós declarativos bootc e equipada com o assistente do sistema herod.

Target Workstation x86_64 / arm64
Áudio Subsystem: PipeWire (Zero-disk)
Default LLM: Qwen3 8B / 4B (Ollama)
Imutabilidade: OSTree / OCI bootc
Segurança: SELinux Enforcing
Início Rápido

Começando em 3 Passos

Do provisionamento atômico à validação com inteligência contextual local sem telemetria externa.

1

Instalação & Boot

Instale a ISO assinada oficial ou faça o rebase dinâmico de qualquer sistema Fedora Silverblue/Bazzite existente via bootc.

Rebase OCI
sudo bootc switch ghcr.io/forjaos/forjaos-nvidia:24.04
2

Diagnóstico Imediato

Valide drivers proprietários NVIDIA/AMD, subsistema Docker rootless, modelos Ollama e chaves de API com o utilitário médico central.

Validação
forja doctor --strict
3

Primeiro Boot & HERO

Ative o assistente Guará chamando "Ei, Guará" ou pressionando Super + Espaço.

Daemon status
systemctl --user status herod
shield

Atenção Crítica: Dual-Boot com Windows BitLocker & MOK

Em sistemas com dual-boot OEM, nunca particione sem backup prévio da chave de recuperação BitLocker de 48 dígitos. Ao carregar módulos proprietários kmod da NVIDIA no primeiro boot com Secure Boot ativado, o prompt do Shim UEFI MOK (Machine Owner Key) solicitará cadastro da senha transitória gerada pelo instalador do ForjaOS.

Arquitetura de Base

Base Atômica & Universal Blue

O ForjaOS abandona os ciclos frágeis de gerenciamento de pacotes convencionais baseados em scripts pós-instalação imperativos. A raiz do sistema operacional (/usr) é completamente read-only, montada como uma imagem OCI imutável gerenciada nativamente por bootc e rpm-ostree.

history

Rollback Instantâneo Determinístico

Se uma atualização quebrar seu pipeline de renderização Godot ou compilador Rust, reinicie e selecione o deployment anterior no GRUB, ou reverta instantaneamente pelo terminal sem perder dados de /var ou /home.

sudo bootc rollback
sync

Staging em Background

Atualizações de sistema são descompactadas em segundo plano de forma passiva através do temporizador bootc-timer. Nenhuma biblioteca em uso é sobrescrita em runtime. A ativação ocorre unicamente via reboot atômico.

systemctl status bootc-update.timer
terminal — bash (Transição para variante CUDA)

$ bootc status

Mascote & Assistente de IA

HERO Daemon (herod em Rust)

Construído em Rust com segurança de memória e latência mínima, o daemon residente de espaço do usuário herod orquestra pipelines sensoriais de áudio, geração de voz e raciocínio de contexto sem tocar em servidores remotos.

security

Garantia NFR-030: Áudio Efetivo Zero-Disk

O pipeline do HERO conecta-se ao servidor de som via nó virtual PipeWire com buffer em anel puramente em memória RAM. O áudio capturado pela Wake Word (openWakeWord calibrado para "Ei, Guará") e a transcrição via faster-whisper small pt-BR são processados e descartados imediatamente. Nenhum arquivo WAV/FLAC é gravado no disco físico.

Pipeline Sensorial & LLM Local

Segurança Operacional

Policy Engine & Tiers de Execução

O assistente do sistema nunca possui permissões cegas de superusuário. Cada MCP tool call interceptada pelo daemon passa pelo Policy Engine formal antes de chegar à syscall do Linux.

Tier Classificação Regra de Prompt Exemplos de Operações Trilha de Auditoria
Livre Leitura e Diagnóstico Execução instantânea silenciosa git status, podman ps, cat log syslog level: INFO
Alterar Modificação de Estado Exige confirmação interativa explícita: [s/N] via diálogo de voz ou clique no toast. mkdir, npm install, systemctl restart journald + AuditEvent gravado
Bloqueado Ação Destrutiva / Perigosa Interceptação imediata. Rejeição incondicional sem override do LLM. rm -rf /, dd if=/dev/zero of=/dev/sd*, mkfs.* Alerta de Segurança + Selinux AVC
Contexto Perpétuo

Memória do Sistema & Vault Markdown

Diferente de assistentes proprietários que trancam suas notas em bases vetoriais remotas opacas, o ForjaOS armazena toda a memória contextual em arquivos Markdown padrão em ~/ForjaOS/vault/. Você possui total posse física, compatível com Obsidian, Logseq e Git.

description

Plain Markdown Vault

Links bidirecionais [[wikilinks]], metadados YAML frontmatter e organização hierárquica por pastas de projetos.

search_insights

SQLite-vec + FTS5

Indexação híbrida local: busca vetorial semântica combinada à busca léxica exata em milissegundos através da extensão embedded SQLite.

hub

Grafo graph.json

Exportação programática do grafo de conhecimento contextual sincronizado para renderização via graphify ou análise em lote.

Interface de Linha de Comando

CLI forja: Subcomandos & Uso

O utilitário unificado forja centraliza todas as ações de manutenção, orquestração de containers de desenvolvimento, injeção de segredos e invocação rápida de modelos de IA.

Referência de Comandos Primários Clique para copiar o comando
forja doctor Diagnóstico

Varre GPU (VRAM/driver), daemon herod, Docker/Podman rootless e integridade do SELinux.

forja setup <target> Provisioning

Configura SDKs em containers isolados distrobox (rust, python, node, gamedev-godot).

forja ai "<prompt>" LLM Direct

Envia prompt direto para a instância local do Ollama, injetando o contexto do git atual.

forja memory Knowledge Graph

Consulta o vault Markdown, reconstrói o índice SQLite e gera o mapa semântico graph.json.

forja game-mode Performance

Altera escalonador de CPU para scx_lavd e suspende daemons de IA para liberar VRAM.

Extensibilidade

Servidores MCP (Model Context Protocol)

O ForjaOS expande a inteligência do sistema através de servidores MCP locais rodando em processos unix-domain-socket. Abaixo está o manifesto base para criação de um plugin de telemetria em Rust:

~/.config/hero/mcp/system-telemetry.rs 
use mcp_sdk::prelude::*;
use forja_policy::{PolicyTier, RequiresApproval};

#[mcp_tool(
    name = "get_gpu_thermal_state",
    description = "Obtém temperatura e consumo atual de VRAM da GPU dedicada",
    tier = PolicyTier::Livre
)]
pub async fn get_gpu_thermal(_ctx: Context) -> Result<ToolResponse, ToolError> {
    let nvml = nvml_wrapper::Nvml::init()?;
    let device = nvml.device_by_index(0)?;
    let temp = device.temperature(nvml_wrapper::enum_wrappers::device::TemperatureSensor::Gpu)?;
    
    Ok(ToolResponse::json(serde_json::json!({
        "gpu_temp_celsius": temp,
        "status": "nominal"
    })))
}
Kernel & Otimizações

Escalonador eBPF scx_lavd & Memória

O kernel 6.12.x-bazzite é compilado com suporte nativo ao sched_ext (eBPF extensible scheduler). Isso permite que cargas de trabalho simultâneas de compilação C++/Rust ocorram sem congelar a taxa de quadros (frametimes) do compositor Wayland do desktop ou de motores gráficos como o Godot Engine.

Status do Escalonador eBPF em Tempo Real

Modo interativo LAVD (Latency-critical Aware Virtual Deadline) ativo por padrão.
